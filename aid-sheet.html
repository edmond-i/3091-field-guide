Photoelectron Spectroscopy

E_binding = E_incident − E_photoelectron
Peak position = binding energy → identity/Z. Peak height/area = e⁻ count in that orbital → configuration.
Trap: isoelectronic species (same e⁻ count) share the exact peak pattern but shift to different positions (more protons → higher BE, shifts left). 1st IE(X⁺) = 2nd IE(X).

Filling Rules

Pauli: no 2 e⁻ share all 4 QNs (max 2/orbital, opposite spin)
Aufbau: lowest energy first
Hund: fill degenerate orbitals singly (∥ spin) before pairing
n+l rule: ascending (n+l); tie → ascending n (4s n+l=4 fills before 3d n+l=5)
Exceptions (half/full-d stability): Cr=[Ar]4s¹3d⁵ · Cu=[Ar]4s¹3d¹⁰ · same pattern: Mo, Ag, Au
Trap: derive config from PT position, don't memorize. Ionizing transition metals → remove ns before (n−1)d, always.

Ionic Bond Energetics

1. Ionize metal: +IE   2. Attach e⁻ to nonmetal: −EA   3. Coulomb attraction of ions: large −ΔE (this is what actually pays for the bond)
Trap: steps 1+2 alone are usually unfavorable — step 3 always wins. Pure element can never bond ionically with itself (needs Δχ>0).

Born–Haber Cycle

ΔH_f = V + IE + ½B(X₂) + EA + U_L
2+/2− case (e.g. CaO): use IE₁+IE₂ and EA₁+EA₂.
Traps: ½B only if ½ mol diatomic gas needed/formula unit. 2nd EA step (X⁻+e⁻→X²⁻) is net endothermic — still used as given data.

Lattice Energy (Born–Landé)

E = −(NₐMZ⁺Z⁻e²)/(4πε₀r₀) × (1−1/n)

Lewis Structures — Algorithm

  1. Arrange: least-χ atom central, H always terminal
  2. Count valence e⁻ (+charge→subtract, −charge→add)
  3. Odd total → radical, incomplete octet, stop
  4. Draw single-bond skeleton
  5. Lone pairs to terminal atoms' octets first
  6. Leftover e⁻ → central atom (hypervalent if >8; only period≥3)
  7. Still missing octet? → lone pair becomes double/triple bond; recheck
FC = valence e⁻ − lone-pair e⁻ − bonding e⁻/2
Best structure: FC→0 (fewest nonzero); any − FC on more-electronegative atom. FC≠oxidation state (FC splits bond 50/50; ox. state gives both e⁻ to more-χ atom).
Sanity check: N→3 bonds/1 LP · O→2 bonds/2 LP · halogen→1 bond/3 LP. Resonance = multiple equal structures, true form is the hybrid.

Don't forget — recitation-flagged traps

  • Cubing volume conversions: 1 m³=10⁶ cm³, not 10².
  • Isotope "A≈atomic mass" shortcut only valid for single-isotope elements.
  • Weighted-avg atomic mass = Σ(isotope mass × fractional abundance).
  • Rydberg eq.: take |value| for λ; emission/absorption only differ by sign.
  • Match units inside one equation (R∞ in J vs eV, matching h's units).
  • Config from PT position, not memorized — that's the actual tested skill.
  • Transition-metal ions: always lose ns electrons before (n−1)d.
  • 1st IE(X⁺) = 2nd IE(X) — a disguised identity in comparison questions.
  • Co²⁺ and friends: favor half/full d-subshell, not "isoelectronic w/ noble gas."
  • PES: height=count, position=identity; isoelectronic ⇒ same pattern, shifted position.
  • Be>B and N>O ionization dips are expected exceptions, not errors.
  • Born–Haber: remember the ½B(X₂) factor whenever only half a mole is needed.
  • O²⁻'s 2nd electron-affinity step is net endothermic, yet still used as given data.
  • Formal charge (50/50 split) ≠ oxidation state (all e⁻ to more-χ atom) — don't conflate.
  • H is always terminal in a Lewis structure, never central.
  • Expanded octets only exist for period ≥3 (accessible d-orbitals) — never C,N,O,F.
