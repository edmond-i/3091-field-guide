L21–22 · Rate & rate law

v = −(1/a) d[A]/dt = +(1/p) d[P]/dt   (M/s)
Instantaneous = slope of the tangent; average = Δ[ ]/Δt. Collision model: needs collisions with E ≥ Ea and the right orientation. Rate ↑ with [ ], T, catalyst.
v = k[A]α[B]β   order = α + β
Exponents come from experiment (initial rates), not coefficients, unless the step is elementary. Two runs: v₂/v₁ = ([A]₂/[A]₁)α; hold the other reactant fixed. k units = M1−ns−1 (units of k reveal the order).
Trap: coefficients ≠ exponents for a multistep reaction; a rate-law exponent can be 0, fraction or negative.

Arrhenius & energy diagram

k = A e−Ea/RT   ln k = ln A − (Ea/R)(1/T)
ln(k₂/k₁) = (Ea/R)(1/T₁ − 1/T₂)
ln k vs 1/T: slope = −Ea/R, intercept ln A. Steeper = larger Ea (more T-sensitive), not “faster”. T in K, Ea in J/mol (R in J).
Diagram: Ea(fwd) = TS − reactants; Ea(rev) = TS − products; ΔE = products − reactants (<0 exothermic). Peak = activated complex/TS; valley = intermediate. Catalyst: lower Ea both ways, same ΔE.
Mechanism: sum of elementary steps; slow step = rate-determining → sets the rate law; intermediates cancel in the overall equation; a catalyst is used then regenerated. Elementary step: exponents = coefficients (molecularity).

L23 · Gibbs free energy & spontaneity

ΔG = ΔH − TΔS   (constant T, P)
ΔG < 0 spontaneous · ΔG = 0 equilibrium · ΔG > 0 not spontaneous as written (reverse is). Spontaneous ≠ fast (rate = Ea, kinetics).
Where it comes from: ΔSsurr = −ΔH/T and ΔSuniv = ΔSsys + ΔSsurr ≥ 0 → ΔG = −TΔSuniv.
ΔHΔSΔG = ΔH−TΔSexample
−+always < 0burning
+−never < 0—
−−< 0 at low Tfreezing
++< 0 at high Tboiling, melting
Crossover T = ΔH/ΔS (ΔG = 0)
Example: ΔH = +44 kJ, ΔS = +118 J/K → T = 44000/118 = 373 K. Above it spontaneous (+,+). At a phase change Tb: ΔG = 0, ΔS = ΔH/T.
ΔG vs T is a line: slope = −ΔS, intercept = ΔH. Max useful (non-PV) work = |ΔG| (wmax = ΔG, system does work if ΔG < 0). ΔG of coupled steps adds.
Trap: ΔH in kJ, ΔS in J/K: ×1000. Kelvin only. A ΔG<0 reaction can still be slow.

Standard values & Hess

ΔH°rxn = ΣnΔH°f(prod) − ΣnΔH°f(react)
ΔG°rxn = ΣnΔG°f(prod) − ΣnΔG°f(react)
ΔS°rxn = ΣnS°(prod) − ΣnS°(react)
ΔH°f and ΔG°f of an element in its standard state = 0; S° of an element is not 0 (only a perfect crystal at 0 K). Multiply by the coefficients. Hess: reverse a step → flip sign; ×n → ×n; add steps → add ΔH (or ΔG).
ΔG° = ΔH° − TΔS° (standard) vs ΔG = ΔG° + RT ln Q (any conditions); ΔH ≈ ΔH°, ΔS = ΔS° − R ln Q.

Rec 16 · Enthalpy, work, entropy

ΔE = Q + W   W = −PΔV
Q + / W + = energy into the system. Expansion (ΔV > 0) → W < 0 (system does work); compression → W > 0. Example: 2.0 atm, ΔV = −1.5 L → W = +3.0 L·atm = +304 J.
Constant V: W = 0, ΔE = Qv. Isothermal ideal gas: ΔE = 0 → Q = −W. Adiabatic: Q = 0. Isolated: ΔE = 0.
H = E + PV   ΔH = ΔE + PΔV = Qp   (gases: ΔH = ΔE + ΔngRT)
ΔH < 0 exothermic (heat out), ΔH > 0 endothermic. State functions: E, H, S, G (path-independent). Path functions: Q, W.
S = k ln W   ΔSuniv = ΔSsys + ΔSsurr ≥ 0
ΔS ↑ when: solid → liquid → gas; more moles of gas (Δng > 0); dissolving/mixing; heating; more particles. S: crystal < amorphous < liquid ≪ gas. Units J/(mol·K).
2nd law: ΔSuniv ≥ 0 (system may decrease if the surroundings gain more). 3rd law: S = 0 for a perfect crystal at 0 K. 1st law: energy conserved.
Trap: sign of W (on system = +); exothermic does not mean spontaneous; entropy of a system can fall in a spontaneous process.

L24 · Equilibrium constant

aA + bB ⇌ cC + dD   K = [C]c[D]d / ([A]a[B]b)
Products over reactants; coefficients are exponents; solids and pure liquids left out; K has no units (Kp for gases in pressure). Reverse: 1/K; ×n: Kn; add reactions: K₁K₂. K ≫ 1 products favoured; K ≪ 1 reactants.
Q vs K (same form as K, any moment): Q < K → right (forward); Q > K → left; Q = K equilibrium.
ΔG = ΔG° + RT ln Q   ΔG° = −RT ln K   K = e−ΔG°/RT
ΔG° < 0 ↔ K > 1; ΔG° = 0 ↔ K = 1; at equilibrium ΔG = 0 and Q = K. Only T changes K (not P, [ ], catalyst).

Constants

R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K)   1 L·atm = 101.3 J   K = °C + 273.15
Kw = 10−14 (25 °C)   ln x = 2.303 log x   NA = 6.022×10²³   ΔH in kJ, ΔS in J/K, R in J: convert!

RICE · van't Hoff · Le Châtelier

RICE: Reaction · Initial · Change (±coefficient·x) · Equilibrium → plug in K. If K tiny and x ≪ initial, drop x (check <5%); else quadratic. Mixing/dilution: use total volume.

L25 · Catalysis & Haber–Bosch

A catalyst gives an alternative path with lower Ea (forward and reverse equally). Unchanged: ΔH, ΔG, K, equilibrium yield. Not consumed; speeds approach to equilibrium. It cannot make ΔG > 0 go.
Homogeneous: same phase as reactants. Heterogeneous: different phase (solid surface). Enzyme: protein catalyst, active site, selective, mild conditions.
N₂ + 3H₂ ⇌ 2NH₃   ΔH = −92 kJ (−46 per mol NH₃)
Fe catalyst, 400–500 °C, high P. High P: 4 mol gas → 2 (Le Châtelier). Exothermic, so low T favours yield but is too slow → compromise. Liquefy NH₃ (polar, H-bonds, higher bp) → removes product, shifts right; recycle N₂ + H₂. H₂ from CH₄ + H₂O → CO + 3H₂ (≈1.8 % of world energy and CO₂).
Ertl (Fe surface): N₂, H₂ adsorb → N≡N splits on the surface; H₂ splits → N–H forms stepwise N → NH → NH₂ → NH₃ → NH₃ desorbs, surface freed.
Sabatier: best catalyst binds intermediately (volcano plot, rate vs binding strength). Too strong: product stays stuck (desorption-limited). Too weak: reactant will not bind/activate. Better catalyst = lower T needed.
Nitrogenase: Fe₇MoS₉C cluster, N₂ + 8H⁺ + 8e⁻ + 16 ATP → 2NH₃ + H₂ at room T, P. N: 0 → −3 (fixation).

L26 · Solutions

ΔHsoln = ΔH₁(solvent–solvent broken, +) + ΔH₂(solute–solute broken, +) + ΔH₃(A–B formed, −)
ΔSsoln > 0, so ΔH usually decides: |ΔH₃| > ΔH₁ + ΔH₂ → exothermic. ΔGsoln = ΔHsoln − TΔSsoln < 0 dissolves. Like dissolves like: polar/ionic in water, non-polar in non-polar.
Solubility vs T is not fixed by the sign of ΔH alone (NH₄NO₃ +25.7 kJ/mol rises; CaCl₂ −68.2 kJ/mol also rises).
M = mol/L solution   m = mol/kg solvent   X = n/ntot
mass % = mass solute/mass soln ×100; ppm = mass solute/mass soln ×10⁶ (dilute water: 1 ppm ≈ 1 mg/L); ppb ×10⁹. Only M changes with T. Dilution M₁V₁ = M₂V₂.

L27 · Acids & bases

Brønsted: acid donates H⁺, base accepts. Conjugate pair differs by one H⁺ (HA/A⁻, BH⁺/B). Water and HCO₃⁻ are amphoteric. Strong acid → negligible conjugate base.
pH = −log[H₃O⁺]   pH + pOH = 14   Kw = [H⁺][OH⁻] = 10⁻¹⁴ (25 °C)
Ka = [H⁺][A⁻]/[HA]   pKa = −log Ka   KaKb = Kw   pKa + pKb = 14
Small pKa = strong acid; stronger acid = weaker conjugate base. pKa: HI −9.3 · HNO₃ −1.4 · H₃O⁺ 0 · HF 3.2 · acetic 4.76 · HCN 9.2 · NH₄⁺ 9.25 · H₂O 14. Weaker X–H bond / more stable A⁻ → stronger (HF < HCl < HBr < HI).
Weak acid: Ka = x²/(C − x) ≈ x²/C → [H⁺] = x ≈ √(KaC). From pH: [H⁺] = 10−pH.
pH = pKa + log([A⁻]/[HA])   (base over acid)
Buffer: weak acid + conjugate base, works at pKa ± 1; equal amounts → pH = pKa; ratio 10 → ±1. Titration: Veq = MAVA/MB moles match; midpoint (½Veq) pH = pKa; equivalence pH: strong/strong 7, weak acid + strong base > 7, weak base + strong acid < 7. Polyprotic: lowest pKa leaves first (alanine COOH 2.34, NH₃⁺ 9.69).
Trap: pH 7 neutral and pH + pOH = 14 hold at 25 °C only; equivalence point ≠ midpoint.

Compare Ksp only for the same formula type: AgCl 1.8×10⁻¹⁰ (x 1.3×10⁻⁵) vs Ag₂CrO₄ 1.1×10⁻¹² (x 6.5×10⁻⁵ — larger solubility).
Q vs Ksp: Q < Ksp unsaturated (more dissolves) · = saturated · Q > Ksp precipitates. Mixing: dilute each ion by the total volume first.
Common ion lowers solubility: PbI₂ in 0.1 M NaI → [I⁻] ≈ 0.1, [Pb²⁺] = Ksp/0.01 = 7.9×10⁻⁷ M (1600× lower). pH: basic anions (OH⁻, CO₃²⁻, PO₄³⁻, F⁻) dissolve more in acid; Mg(OH)₂ less soluble at high pH.
Complexation: ligand binds the metal ion → lowers free [M], Q < Ksp, solid dissolves (opposite of common ion). EQ:Kf = K₁K₂K₃K₄
Big Kf = stable. Chelators (EDTA, 6 donor atoms) are extreme. AgBr + S₂O₃²⁻ → [Ag(S₂O₃)₂]³⁻ (Kf 2.9×10¹³) fixes film; Nd/Dy magnet recycling: ligand holds Nd³⁺, Dy precipitates. Karst: CaCO₃ + CO₂ + H₂O ⇌ Ca²⁺ + 2HCO₃⁻ (reverse deposits stalactites).

Order of attack for any problem

① write the balanced equation · ② write K / Ksp / rate law (solids out) · ③ units: K, J vs kJ, K not °C · ④ RICE or Q vs K · ⑤ sanity check (does the sign / direction match Le Châtelier?) · ⑥ “briefly explain” needs a reason, not just the answer.
